# CPublishr Backend

Scaffold rebuilt from PRD with a minimal MVP path that runs end-to-end.

- Backend API: `backend/src`
- Contracts + examples: `backend/src/contracts`, `backend/contracts/examples`
- Docs: `docs/`
- Local infra: `infra/docker/docker-compose.yml`

Node 0 input contract:
- Required: `project_id`, `topic_title`, `core_idea`, `tone_preference`, `distribution_targets`
- Optional: `user_content`, `target_audience`, `content_depth`
