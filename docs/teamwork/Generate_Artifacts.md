# Artifacts Developer Guide

This document describes the current artifact generation contract and extension path.

## Current model

Each artifact format is generated by a builder under:
- `backend/src/services/orchestration/artifacts/formats/`

Each builder returns one `ArtifactDraft` using a common payload envelope.

## Builder contract

Your format module must export module-level `BUILDER`.

Required:
- builder class defines `kind` and `formats`
- builder implements `build(self, *, fmt: str, ctx: PipelineContext) -> ArtifactDraft`
- module exports `BUILDER = YourBuilder()`

`backend/src/services/orchestration/artifacts/formats/registry.py` auto-discovers builders by importing format modules and checking `module.BUILDER`.

## Kind-scoped style settings (current)

Artifact generation request supports:
- `style_settings_by_kind`
- `style_settings_by_format`

Effective settings for each format are resolved by orchestrator as:
- `style_settings_by_kind[get_kind(fmt)]`
- merged with `style_settings_by_format[fmt]`

Legacy shared `style_settings` fallback is intentionally ignored for effective per-format style merge.

## Pipeline context available to builders

From `PipelineContext` (`backend/src/services/orchestration/artifacts/contracts.py`):
- project/content: `project_id`, `topic_title`, `core_idea`, `master_body`, `seed_keywords`
- audience/tone: `target_audience`, `detail_level`, `tone_preference`
- style:
  - `style_settings` (effective merged settings for this format)
  - `style_settings_by_kind`
  - `style_settings_by_format`
  - `image_style_settings`
  - `video_style_settings`

## Current kinds and formats

- `text`: `caption`, `post`, `newsletter`, `blog`, `script_short`, `cta_variants`
- `image`: `post_image`, `thumbnail`, `banner`, `cover`
- `video`: `gif`, `reel`, `short_video`

## Output schema

Return `ArtifactDraft` with:
- `format`
- `title`
- `payload_json`
- `tags_json`
- optional: `status`, `revision`, `parent_artifact_id`

`payload_json` should use `default_payload_template()`:

```json
{
  "version": "1.0",
  "body": null,
  "items": [],
  "assets": [],
  "prompts": [],
  "settings": {},
  "notes": null
}
```

## Persistence behavior (important)

Flow:
1. `POST /api/v1/artifacts/generate`
2. `ArtifactPipelineOrchestrator.generate(...)`
3. resolve builder by format
4. `builder.build(...)`
5. normalize/validate payload
6. persist artifact row

Media persistence rule:
- kinds `image`, `video`, `gif` are persisted only when draft status is exactly `generated`
- failed/partial/simulated media drafts are skipped

## Image/Video style notes

UI currently sends `include_master_content` for image/video style settings.
- image builder reads this flag and conditionally appends master-content reference
- video builder reads this flag and conditionally appends master-content reference

Theme and subject/core prompt are treated as mandatory in UI; video builder also enforces this at backend level.

## Add new format checklist

1. Add `backend/src/services/orchestration/artifacts/formats/<new_format>.py`
2. Implement builder + export `BUILDER`
3. Ensure `kind` and `formats` are set
4. Return valid envelope payload
5. Restart backend
6. Verify:
   - `GET /api/v1/artifacts/catalog/formats`
   - UI format list
   - `POST /api/v1/artifacts/generate`
